# Definition of Done

1) All acceptance criteria defined in the user story are met
    - the code does what it needs to do
2) All code is complete, follows team standards and is rigorously tested
    - the code compiles and is free of any bugs, including functional, logical, regression and integration bugs
3) Unit tests are defined and complete
    - the code has unit tests when relevant
4) New features and code are fully documented when necessary
    - the code has comments, the README is updated, graphs are made, etc
5) All relevant code is reviewed and successfully integrated or merged
    - a pull request is made, someone reviews your work and the commit is fully integrated into main
6) Feature is accepted by the Product Owner
    - Product Owner makes sure that all of the above rules are being followed
